\chapter{Computational methodology}\label{ch:computation}
\label{sec:arithmetic}\label{sec:optimiser}
Python 3.12+ permits readable formulas: immutable dataclasses preserve contractual inputs; \texttt{bonds.py}, \texttt{curves.py} and \texttt{risk.py} separate nominal valuation, curve fitting and zero discounting. This prevents conflating rate conventions. NumPy supplies arrays and linear initialisation; SciPy supplies nonlinear \texttt{least\_squares} \parencite{harris2020,virtanen2020}. The trust-region reflective algorithm restricts successive local steps and respects parameter bounds \parencite{scipyLeastSquares,branch1999,nocedal2006}. Six fixed decay starts precede joint fitting; successful candidates compete on residual sum of squares (\cref{sec:reproduce-fit}).

\label{sec:test-method}\label{sec:tolerances}
Deterministic tests use fixed inputs to check identities, monotonicity, synthetic fits, invariants and boundaries. Finite differences approximate derivatives from displaced prices; central differences use symmetric displacements. Numerical tolerances specify acceptable discrepancies; truncation error comes from omitted approximation terms. Offline execution and recorded library versions support reproducibility (\cref{app:reproducibility}).
