\chapter{Computational methodology}\label{ch:computation}
\label{sec:arithmetic}\label{sec:optimiser}
The implementation uses Python 3.12+. Immutable dataclasses preserve contractual inputs, while \texttt{bonds.py}, \texttt{curves.py} and \texttt{risk.py} separate nominal valuation, curve fitting and zero discounting. This makes the distinct conventions visible; callers must still supply the correct rate interpretation. NumPy supplies arrays and linear initialisation; SciPy supplies nonlinear \texttt{least\_squares} \parencite{harris2020,virtanen2020}. The trust-region reflective algorithm restricts successive local steps and respects parameter bounds \parencite{scipyLeastSquares,branch1999,nocedal2006}. Six fixed decay starts precede joint fitting; the successful candidate with the smallest residual sum of squares is selected (\cref{sec:reproduce-fit}). Conditioning describes how sensitively the exact solution changes under small input perturbations. Gilli and colleagues identify local optima and poor conditioning as separate difficulties and study a broader search heuristic \parencite{gilli2010}. These difficulties remain possible with the engine's finite set of local starts.

\label{sec:test-method}\label{sec:tolerances}
Deterministic tests use fixed inputs to check identities, monotonicity, synthetic fits, invariants and boundaries. Finite differences approximate derivatives from displaced prices; central differences use symmetric displacements. Numerical tolerances specify acceptable discrepancies; truncation error comes from omitted approximation terms. Offline execution and recorded library versions support reproducibility (\cref{app:reproducibility}).
