\section{Calibration algorithm and stopping criteria}\label{sec:optimiser}
% Explain local minimum/nonlinear least squares before algorithm details.
% Installed defaults: Trust Region Reflective, linear loss, two-point numerical
% Jacobian. Branch et al. is background, not a claim that every method in it is used.
\plan{Discuss the algorithm with \textcite{scipyLeastSquares,branch1999,nocedal2006}.

Confirm defaults against the installed signature during reproduction.}
\begin{enumerate}
\item Initialise decay scales at \((0.5,2),(1,5),(2,10),(5,1),(10,3),(3,15)\)
years; initialise the four coefficients by linear least squares at each start.
\item Jointly optimise all six parameters, with unbounded coefficients and
decay bounds \([0.01,100]\) years; scale residuals to basis points.
\item Use Jacobian-based scaling, \texttt{ftol=xtol=gtol=1e-10} and
\texttt{max\_nfev=3000} per start.
\item Select the successful finite bounded candidate with the smallest decimal
residual sum of squares; exact ties retain the earlier start.
\end{enumerate}

\subsection{Error measures and tolerances}\label{sec:tolerances}
Let \(a_{\mathrm{num}}\) be a computed scalar and \(a_{\mathrm{ref}}\) its
reference. Absolute tolerance \(\varepsilon_{\mathrm{abs}}\) has the scalar's
units; relative tolerance \(\varepsilon_{\mathrm{rel}}\) is dimensionless.
A common comparison rule is
\begin{equation}\label{eq:tolerance}
|a_{\mathrm{num}}-a_{\mathrm{ref}}|
\leq\varepsilon_{\mathrm{abs}}+\varepsilon_{\mathrm{rel}}|a_{\mathrm{ref}}|.
\end{equation}
