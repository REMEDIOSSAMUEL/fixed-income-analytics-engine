\section{Finite differences and convergence}\label{sec:verify-differences}
A finite difference approximates a derivative using displaced function
values. A central difference uses both signs about the same point.
Truncation error arises from omitted Taylor terms, before rounding.
\begin{align}
\frac{P(\yytm+h)-P(\yytm-h)}{2h}
 &=P'(\yytm)+O(h^2),\label{eq:central-first}\\
\frac{P(\yytm+h)-2P(\yytm)+P(\yytm-h)}{h^2}
 &=P''(\yytm)+O(h^2).\label{eq:central-second}
\end{align}
