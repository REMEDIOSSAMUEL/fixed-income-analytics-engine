\section{Calibration settings}\label{sec:reproduce-fit}
Initial decay pairs, in years, are \((0.5,2),(1,5),(2,10),(5,1),(10,3),(3,15)\).
Each seeds linear least-squares coefficients, followed by joint six-parameter optimisation. Coefficients are unbounded; both decay scales lie in \([0.01,100]\) years. At least six distinct positive maturities are required; observations have equal weight, including repeated tenors.

Optimisation residuals are \(10^4e_\ell\). The installed \texttt{least\_squares} defaults are trust-region reflective, linear loss and a two-point numerical Jacobian (a matrix of residual derivatives). The code specifies Jacobian-based scaling, \texttt{ftol=xtol=gtol=1e-10} and \texttt{max\_nfev=3000}. These tolerances control termination through objective, step and gradient criteria; they are not bounds on financial error. Function counts exclude extra residual calls for numerical Jacobians \parencite{scipyLeastSquares}.

Only successful, finite, bounded candidates qualify; smallest unscaled residual sum of squares wins, with earlier-start tie breaking. Failure of all starts raises an error. This procedure is a local search, not a guarantee of global optimality.
