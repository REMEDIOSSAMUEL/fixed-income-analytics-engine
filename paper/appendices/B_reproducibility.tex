already exist; select an installed Python version of at least 3.12.
Dependency installation may require network access; analytical execution
uses only the offline inputs.

\section{LaTeX toolchain and compilation}
Use an installed pdfLaTeX toolchain with \texttt{latexmk}, \texttt{biblatex}
and \texttt{biber}; no Python dependency is required for typesetting.
The bibliography uses one author--year system throughout.
\begingroup\footnotesize
\begin{verbatim}
latexmk --version
biber --version
Push-Location .\paper
try {
    latexmk -pdf -interaction=nonstopmode -halt-on-error -outdir=build main.tex
    if ($LASTEXITCODE -ne 0) { throw "LaTeX compilation failed." }
} finally {
    Pop-Location
}
\end{verbatim}
\endgroup
The expected PDF is \path{paper/build/main.pdf}.
Auxiliary files, including the bibliography build products, belong in
\path{paper/build/}. The existing repository rule \path{build/} already
ignores this directory; no global PDF ignore rule is introduced.
The skeleton was compiled with latexmk 4.88, Biber 2.22 and
pdfTeX 1.40.29 (MiKTeX 26.5). The bibliography was processed successfully
by Biber as part of the latexmk build.
